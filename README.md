# Advent of code

This repository will (hopefully) contain most solutions to the [advent of code](https://adventofcode.com/) puzzles.

## How to run this project

```sh
# install packaged
$ composer install

# run specific year
$ php app "2025"

# run specific year/day
$ php app "2025/01"

# run specific year/day-part
$ php app "2025/02-02"
```

## PSA

Not all solution might be my own. Though I hope most of them will be.
